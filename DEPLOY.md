# Развёртывание Garage AI

## 1. Создать сайт из GitHub
1. Открой https://dash.cloudflare.com/ и войди в аккаунт Cloudflare.
2. Перейди в **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Подключи GitHub, выбери репозиторий `daniilv95299-code/garage-ai` и production branch `main`.
4. Для простого статического проекта без сборки укажи build command пустым, а build output directory — `.` (корень репозитория). Если интерфейс Cloudflare предлагает иной обязательный вариант, не запускай деплой до проверки настройки.
5. Нажми Save and Deploy. Cloudflare выдаст адрес вида `https://имя.pages.dev`.

## 2. Подключить ИИ
1. В Cloudflare открой созданный Pages-проект.
2. **Settings → Functions → Bindings → Add → Workers AI**.
3. В поле **Variable name** введи строго `AI`.
4. Сохрани привязку и выполни новый deployment (Redeploy).
5. Проверь чат: отправь вопрос «Какие данные нужны для подбора зазоров двигателя?».

## 3. Что важно
- Если ответ сообщает, что AI binding не подключён, проверь имя `AI` и сделай redeploy.
- Использование Workers AI регулируется тарифом и лимитами аккаунта Cloudflare; проверь текущие лимиты/стоимость в Cloudflare перед активным использованием.
- Поиск веб-источников сейчас использует DuckDuckGo HTML, он может не сработать или вернуть неполные результаты. Ссылки не гарантируют, что найденная страница — заводское руководство.
- Точные моменты затяжки, зазоры и распиновки нужно сверять с заводским руководством для конкретной модификации.
- Не добавляй API-ключи или другие секреты в файлы GitHub. Если позже подключим внешний API, секрет добавляется только через Cloudflare Settings → Variables and Secrets → Add → Encrypt.

## Текущая архитектура
- `index.html` — интерфейс чата.
- `functions/api/chat.js` — endpoint `POST /api/chat`, поиск и запрос к модели.
- `docs/AGENT_INSTRUCTIONS.md` — правила точности и формат ответов.

## Ограничения первой версии
- История диалога не сохраняется на сервере.
- Поиск — базовый; источники нужно проверять.
- В публичном проекте нет авторизации. Не отправляй персональные данные или секреты.
